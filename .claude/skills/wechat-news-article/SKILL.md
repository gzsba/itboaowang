# 微信公众号新闻稿生成

## 用途

从项目 `index.html` 的焦点新闻（`a.news-highlight`）中选取一条，搜索补充细节，按新华网通讯社风格撰写一篇600字以内的微信公众号文章，输出为 Markdown 文件。

## 执行流程

### 第1步：选取新闻

1. 读取项目根目录下的 `index.html`。
2. 定位 `class="news-highlight"` 的 `<a>` 元素，提取焦点新闻（通常2条）。
3. 从中选取1条。选取标准：时效最新、话题热度最高、信息最完整。
4. 记录该新闻的标题、摘要、来源链接。

### 第2步：搜索补充细节

1. 用 `mcp__web-search__web_search` 搜索该新闻的详细信息。
2. 中英文关键词并行搜索，覆盖：发布详情、数据参数、行业背景、相关人物/机构言论、对比信息。
3. 用 `WebFetch` 抓取2-3篇高质量来源全文（优先官方发布、权威媒体）。
4. 提炼关键事实：时间、地点、人物、数据、原因、影响。

### 第3步：撰写文章

**风格要求：新华网通讯社风格**

- 客观、平实、准确，不带主观情绪和营销化表述
- 连贯段落叙述，不使用分块小标题、不使用列表/要点
- 导语第一段一次性交代：时间、事件、核心数据、意义
- 用"业内人士指出""据了解"等引语代替主观评价
- 数据准确，表述严谨，避免夸大
- 结尾以行业趋势收束，升华但不空洞

**篇幅要求：600字以内**（不含标题）

**结构要求：**
- 标题：简洁有力，主标题+副题意涵，不超过25字
- 导语：一段，概括全文核心
- 正文：2-3段，展开关键事实和数据
- 结尾：一段，行业意义或趋势升华

**禁止：**
- 不署来源
- 不标注"IT宝网"或任何自媒体标识
- 不使用"卖点""组合拳""炸场"等营销词汇
- 不使用分块小标题（## ###）和列表（- / *）
- 不添加emoji

### 第4步：输出文件

1. 确认 `news_document` 目录存在，不存在则创建。
2. 文件名格式：`YYYY-MM-DD-新闻标题.md`
   - 日期取新闻发布日期
   - 标题取新闻主标题，用短横线连接关键词
   - 示例：`2026-08-03-阿里发布千问3.8-MAX-2.4万亿参数比肩全球前沿.md`
3. 用 `Write` 工具写入文件。

## 质量检查

完成后检查：
- [ ] 篇幅在600字以内
- [ ] 无分块小标题和列表
- [ ] 无来源标注和自媒体标识
- [ ] 数据准确，与搜索结果一致
- [ ] 新华网通讯社风格
- [ ] 文件名格式正确
