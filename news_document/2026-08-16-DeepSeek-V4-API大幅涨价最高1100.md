# DeepSeek V4 API大幅涨价，最高涨幅达1100%

中国人工智能初创企业深度求索（DeepSeek）于8月16日16时（UTC）正式上调V4-Flash和V4-Pro两款模型的API价格，涨幅从50%至1100%不等，同时引入峰谷分时计费机制。此举标志着DeepSeek自年初以低价策略冲击市场以来，首次大规模调整定价体系。

根据DeepSeek官方公布的价格方案，V4-Flash输出token在峰值时段升至每百万1.32美元，谷值时段为0.66美元，较此前0.28美元的统一定价最高上涨约371%。V4-Pro输出token峰值价格升至3.96美元，谷值为1.98美元，此前为0.87美元。输入token价格同步上调，V4-Flash缓存未命中输入token峰值升至0.44美元，V4-Pro升至1.32美元。峰值时段定义为UTC时间每日1时至4时及6时至10时，谷值价格为峰值的一半。

DeepSeek表示，此次调价旨在更合理地分配计算资源，通过分层定价引导开发者将工作负载转移至低峰时段。业内人士指出，DeepSeek在一个月前刚发布V4-Flash轻量模型时，曾被研究机构Artificial Analysis评为全球性价比最高的AI模型，此前还曾对V4-Pro实施75%的促销折扣。短短数月内定价策略发生如此显著转变，反映出大模型算力成本压力与商业化盈利需求之间的矛盾日益凸显。

值得注意的是，DeepSeek近期已完成首轮超70亿美元的外部融资，并开始为首次公开募股做准备。此次涨价被视为企业在上市前改善财务表现的重要举措。即便如此，DeepSeek涨价后的价格仍低于部分海外竞品。以Anthropic旗下Fable 5模型为例，其输出token价格为每百万50美元，约为DeepSeek V4-Pro峰值价格的12.6倍。

此次定价调整发生于全球大模型竞争格局加速演变的关键节点。OpenAI旗下GPT-5.6 Luna于7月底降价80%后已成为ChatGPT免费默认模型，谷歌Gemini月活跃用户突破10亿。分析人士认为，随着前沿模型性能差距缩小，价格因素在企业选型中的权重持续上升，DeepSeek此番涨价或将影响其在开发者群体中的价格优势认知，但也在一定程度上验证了中国AI企业从价格战向价值竞争转型的行业趋势。
