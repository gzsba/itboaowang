# xAI推出Grok Code Fast 1免费编程模型，AI编程门槛降至零

马斯克旗下人工智能公司xAI于8月29日发布专为编程场景设计的新模型Grok Code Fast 1，目前处于限时免费期，已接入Cursor、GitHub Copilot、Cline、Windsurf等主流编程平台。

据了解，该模型生成速度达到每秒约190个token，上下文窗口为256k，可记忆大半个代码项目。在业界公认的SWE-bench Verified编程测试中，Grok Code Fast 1取得70.8%的准确率，与顶尖模型处于同一梯队。正价输入为0.2美元每百万token、输出1.5美元每百万token，较多数通用大模型低一个数量级。

该模型支持Python、TypeScript、Java、Rust、C++、Go等多种编程语言，用户无需具备专业编程背景，通过自然语言描述需求即可让AI完成建网页、修复程序错误、制作下单页面等任务。业内人士指出，Grok Code Fast 1将"快速、低成本、免费可用"三个特征同时摆到普通用户面前，意味着AI编程正在从程序员的生产力工具向大众化应用方向延伸，编程技能获取门槛显著降低。

随着各大科技公司纷纷加码编程模型赛道，AI编程工具竞争格局加速演变，技术普惠将成为行业发展的核心趋势。
